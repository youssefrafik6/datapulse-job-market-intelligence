# Source verification and selection

The pipeline pins both built-in downloads to immutable Hugging Face revisions and checks the exact bytes returned by those pinned download URLs. Original files, local databases and trained artifacts stay on the operator’s machine. Review dated November 26, 2026.

| Source | Files inspected and contents | Decision |
| --- | --- | --- |
| [DataForge / Zalize Tier S](https://huggingface.co/datasets/zalizedata/tech-job-postings-salary-dataset) | 35,417 Parquet rows, 22 fields, 65 country labels. Public ATS boards, job IDs/URLs, employer, location, remote flag, skills, posting and collection dates, salary bounds, currency and period. 13,931 rows populated a raw lower salary bound. 13,371 U.S. rows retained, no repeated IDs in that subset. All retained rows carried a Python tag. Raw posting dates range from January 2020 to August 2026 in the August 2026 export. | Use for noncommercial salary exploration and model evaluation. Single exported cross-section of surviving postings. Disable trend chart for this source. Keep its separation from the 2023 cohort. |
| [Nikhil Nalawade mirror](https://huggingface.co/datasets/nikhilnalawade/data_jobs) | Downloaded five CSVs. Main 17-column postings file has 785,741 rows, 160 country labels, dates throughout 2023, 22,003 populated reported annual figures and 668,704 populated skill-list strings. Auxiliary files contain 139,982 companies, 3,660,283 job-skill relationships, 785,741 salary rows and 880 skill labels. The data dictionary file is empty. | The card says MIT but provides little collection provenance. The postings match the original Luke file’s shape and coverage, with an EXCEPT ALL query finding 631 mirror rows without identical upstream values. Use the original collector’s release and license. |
| [Luke Barousse Data Jobs](https://huggingface.co/datasets/lukebarousse/data_jobs) | Downloaded pinned original 17-column CSV. 785,741 observations from 160 country labels between January 1 and December 31, 2023. Search results collected through SerpApi/Google from multiple listing platforms. Published fields include employer, calculated country, work-from-home signal, location, salary figures and source skill tags. No stable ID, currency, raw description, employer size or collection timestamp in this file. | Primary source for historical skill, role and regional analyses. Retain 204,273 U.S. rows after removing 2,019 heuristic duplicates. Keep any reported salary values separate from verified advertised USD. The collection approach can shift by month. |
| [Adzuna](https://developer.adzuna.com/) | Key and app ID required. Search provides snippets and can return Jobsworth estimates, marked separately. A full dataset audit depends on authenticated access. | No live ingestion or schedule. Usage limits depend on the account. Published research and listings carry attribution obligations. Organizational use beyond evaluation requires agreement as applicable. See the [API terms](https://developer.adzuna.com/docs/terms_of_service). |

## Coverage rules

The dataset’s structured country gate determines the U.S. subset. Search location is not used as posting location. Conflicts in source country coding can still affect geography. State parsing requires explicit recognizable evidence, and some multi-location labels stay unassigned. NYC uses explicit city or borough evidence. Remote is based on source flags and location wording, with unspecified arrangements left visible.

The same job can occur in both sources. Each is an independent cohort. The number loaded across both sources is a storage count and does not deduplicate across publishers. See the JSON quality reports for acceptance counts, reasons and denominators.
